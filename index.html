    What the demo computes

    The page computes n‑gram counts and TF‑IDF from a small set of invented examples. A toy scoring rule uses those features to supply five illustrative classifier probabilities per voter. The three voting levels average those probabilities. The paper’s trained models and evaluation data are separate from this demo.
